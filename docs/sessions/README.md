# Sessions

Mỗi tháng một file `YYYY-MM.md`, **entry mới nhất lên đầu**. Không sửa entry cũ; sửa hiểu nhầm thì
thêm entry mới ghi rõ "corrects <entry>".

Entry trả lời 5 câu: **làm gì** · **học được gì và đã ghi vào file nào** · **còn mở** · **file tạo/sửa** ·
**verify thế nào**. Session log chỉ là con trỏ — nội dung durable phải nằm trong file chủ đề
(`architecture.md`, `decisions.md`, `adr/`, `<domain>-<topic>.md`).

## Template

```md
## YYYY-MM-DD — <tiêu đề ngắn>

**Làm:** …
**Học được → đã ghi vào:** <fact> → `docs/<file>.md` §…
**Còn mở:** …
**File:** tạo `…`; sửa `…`
**Verify:** …
```
